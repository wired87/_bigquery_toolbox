## CLI Usage

This toolbox includes a CLI for uploading data and chatting with your BigQuery data using AI.

### Setup
1. Create a virtual environment and install dependencies:
   \\\ash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   \\\
2. Ensure you have Google Cloud credentials set up (e.g., \gcloud auth application-default login\).

### Commands

#### Upload Data
Upload a CSV or JSONL file to a BigQuery table.
\\\ash
python cli.py upload path/to/file.csv my_table_name
\\\

#### AI Chat
Start an interactive chat session to query your data using natural language.
\\\ash
python cli.py chat
\\\
The chat supports:
- Listing datasets and tables.
- Getting table schemas.
- Running SQL queries generated by AI.
- Semantic search (Vector Search) if configured.


### Data Ingestion
The CLI automatically scans the \./data_dir\ for CSV, Excel, and JSONL files when starting a chat.
1. Place your files in \data_dir\.
2. Run \python cli.py chat\.
3. Enter a 'Knowledge Base Name' (Table Name).
4. The CLI will ingest the data, generate embeddings, and start the chat context.


### Simplified Usage
The CLI is now chat-centric.
1. Run \python cli.py\.
2. Enter the Knowledge Base Name.
3. The AI will classify your intent (e.g., Search vs. Chat) and provide streaming responses.


### Credentials
The CLI will prompt you for the path to your \credentials.json\ file at startup.
Ensure you have a valid Google Cloud Service Account key file.


### Troubleshooting
- **Ingestion Errors**: Ensure your data files are valid CSV/Excel/JSON.
- **Embedding Errors**: You must have a BigQuery ML remote model named \embedding_model\ in your dataset.


### Automatic Setup
The CLI now attempts to automatically create the necessary BigQuery Connection and Remote Model for embeddings.
If it fails due to permissions, it will output instructions on how to grant the 'Vertex AI User' role to the connection's Service Account.


### Credentials Update
The CLI now automatically looks for \credentials.json\ in the project root directory.
No manual entry is required.
